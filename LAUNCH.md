# Launch and distribution

Live since 2026-11-22 at https://theguysaccount.github.io/set-u-language-genealogy/, beside the live atlas at
https://www.set-u.org/. Machine channels only; nothing is posted by or as a person.

| Channel | How |
|---|---|
| Search | Indexed: the home page ("SET-U open data", "etymology dataset download", "etymology graph dataset"), `/data/` and `/data/citations/`. Word pages are `noindex` and point at set-u.org, so this edition never competes with it. |
| IndexNow | Every deploy submits the indexable URLs. |
| Account root | `theguysaccount.github.io/robots.txt` lists this sitemap within a day. |
| Developers | Stable file URLs (`/data/<dataset>.json`, `.csv`, `set-u-atlas.sqlite`, `manifest.json`) to cite and script against. |
| GitHub | Public repo with description, topics and README. |

## Domain

The natural address is a subdomain of set-u.org (DNS at Namecheap), for example `data.set-u.org`. The domain rollout
session sets it up; the exact record and settings are in OPERATIONS.md ("Custom domain"). Nothing has been changed.
